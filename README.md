# Circle of Death by Piso

Un drinking game mobile-first pensato per essere giocato da un intero gruppo con un solo telefono.

## Come funziona

- Da 2 a 12 giocatori.
- 52 carte e 52 sfide diverse.
- Numero e seme determinano insieme la regola.
- Nessuna sfida a categorie o catene di parole.
- Il quarto Re chiude la partita.

Le penalità possono sempre diventare acqua o analcolico. Fermarsi o saltare una sfida è sempre consentito.

## Sviluppo

```bash
npm install
npm run dev
```

Per verificare la versione di produzione:

```bash
npm run build
node --test tests/rendered-html.test.mjs
```
